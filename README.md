# hospital-information-management-system
A Flask-based Hospital Information Management System for patient data collection, validation, SQLite database management, and interactive healthcare data visualization using Plotly.


A web-based **Hospital Information Management System (HIMS)** developed using **Python, Flask, SQLite, HTML, CSS, JavaScript, and Plotly**.

This project collects and manages patient information, validates user inputs, stores records in a SQLite database, and presents patient statistics through an interactive dashboard.

## Features

* Patient information collection
* Input validation
* SQLite database integration
* Flask backend
* HTML, CSS and JavaScript frontend
* Patient data management
* Interactive dashboard
* Plotly data visualization

## Patient Information

The system collects information including:

* Full Name
* Date of Birth
* Age
* Gender
* Marital Status
* Mobile Number
* Email Address
* Address
* City
* State
* Pincode

## Installation

Clone the repository:

```bash
git clone https://github.com/sanabhatia18/hospital-information-management-system.git
```

Navigate to the project folder:

```bash
cd hospital-information-management-system
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the Flask application:

```bash
python app.py
```

Open the local URL shown in the terminal.
